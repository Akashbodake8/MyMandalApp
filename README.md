# MyMandal App

MyMandal is a professional finance management application designed for Mandals (community organizations). It allows Treasurers to track donations, expenses, and generate professional PDF receipts, all while maintaining a secure and organized record-keeping system.

## Key Features

- **Treasurer Account Management**: Secure registration and login for organization treasurers.
- **Financial Year Isolation**: Keep organization records separated by festival/financial years.
- **Donation & Expense Tracking**: Easily record income (monetary and in-kind) and organization spending.
- **Professional PDF Receipts**: Generate high-quality A4 donation receipts with organization branding.
- **Local Organization Branding**: Add your Mandal's logo and stamp. Stamps are stored locally on your device for maximum privacy and offline availability.
- **Balance Summaries**: Real-time calculation of opening balance, total income, total expenses, and current organization funds.
- **Transaction History**: View and edit past records with audit indicators for modified entries.
- **Cloud Persistence**: Secure data storage powered by Firebase Firestore, with robust organization-level data isolation.

## Technical Requirements

- **Android Version**: Android 7.0 (API level 24) or higher.
- **Internet Connection**: Required for data synchronization with Firebase.
- **Storage**: Local storage used for organization branding images.

## Installation

1. Download the latest APK from the [Releases](https://github.com/yourusername/MyMandalApp/releases) section.
2. Install the APK on your Android device (ensure "Install from Unknown Sources" is enabled if necessary).
3. Open the app and follow the registration flow to set up your organization's Treasurer account.

## Development Setup

To build the project from source:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/MyMandalApp.git
   ```
2. Open the project in Android Studio.
3. Add your own `google-services.json` file to the `app/` directory.
4. Sync the Gradle project and build.
